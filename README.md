# e-Procurement (MVP)

Generic, 1C-free procurement platform: one end-to-end procurement from vendor registration to a
vendor-accepted purchase order, for the management demo (13 Nov 2026).

- Scope and acceptance criteria: [`docs/backlog.md`](docs/backlog.md)
- Rules for contributors and Claude Code: [`CLAUDE.md`](CLAUDE.md)
- Setup, migrations, seeding and Vercel: [`docs/SETUP.md`](docs/SETUP.md)
- Status per slice: [`docs/PROGRESS.md`](docs/PROGRESS.md)

Stack: Next.js (App Router, TypeScript), Supabase (Postgres + RLS, Auth, Storage, Realtime), Tailwind,
shadcn/ui, next-intl. Synthetic demo data only.
